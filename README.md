## ✨ Features

- **Cloud Stockfish + Lichess GM Engine:** Plays strongest moves via dual-parallel cloud analysis (`chess-api.com` + `lichess.org` d50+ cloud book) with built-in local fallback.
- **Fast Mode:** Single quick query mode optimized for 1–3 minute Blitz/Bullet matches.
- **Human Behaviour Simulation:** Configurable Engine Level (1–6), Think Time, and Min/Max move delay for legit pacing.
- **Manual Best Move:** Instant one-shot button to play the best move on your turn.
- **Puzzle Auto-Solver:** Solves Rated, Daily, and Puzzle Rush puzzles using the game's solution line (+ Auto Next).
- **Daily Goal Farm:** Automated farming across bot matches (`pip`, `clover`, `bramble`, `maple`, `flint`, `sable`, `onyx`), puzzles, and lessons.
- **Anti-AFK & Fluent UI:** Blocks 20-minute idle kicks with a sleek acrylic interface.
